This thesis aims to bridge the gap between the deaf-mute community and individuals wishing to learn sign language gestures, utilizing the ASL dataset and the Python programming language. Its operation relies exclusively on a standard 2D RGB camera, ensuring the program is accessible to all users. The work is divided into two parts: The first phase involves extracting our data and subsequently training the model for use with a live camera feed. To implement this part, the MediaPipe library was utilized to analyze 21 hand landmarks, while the Random Forest algorithm was employed to classify the various gestures. The second phase focused on creating a "word builder" capable of displaying the letters formed by the user and assembling them into words or even full sentences. Our code includes several variables that govern its performance. Ιn the accuracy test, it achieved a rate of 97.89%, a result underpinned by the use of deep neural networks and specialized libraries designed to effectively handle problems of this nature.
